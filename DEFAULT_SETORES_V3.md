# Default de setores — ProteínaFlow V3

Referência gerada a partir do catálogo inicial de 268 itens. O SQL 16 aplica a mesma lógica aos itens que já existem no banco e não sobrescreve ajustes manuais posteriores.

- Sushi Bar: 132 itens
- Poke: 80 itens
- Cozinha: 56 itens
- Marcados para revisão administrativa: 75 itens

Regras principais: POKE/BOWL explícito no nome → Poke; sushi/sashimi/nigiri/temaki/rolls etc. → Sushi Bar; itens quentes/Mex (yakisoba, guioza, harumaki, frango, katsu, burrito, taco etc.) → Cozinha. Rodízios genéricos ficam em Sushi Bar por segurança, mas marcados **Revisar setor**.
